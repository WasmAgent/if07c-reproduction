## README version reference (documentation only)

## ARTIFACTS.json generatedAtUtc provenance defect

The `generatedAtUtc` field in the v1.0.2 candidate ARTIFACTS.json reads:

    2026-10-05T08:00:00.000Z

The candidate commit dc89f830a5ba9234944ed644fc4225c67f81a44d was created at 06:49:31Z
and the release was published at 07:35:32Z. The recorded timestamp is therefore later than
both events and was hand-written rather than machine-generated at the time of artifact
construction.

Impact assessment:

- manifest file hashes: NOT AFFECTED (sha256 of each file, independent of this field)
- package tarball SHA256: NOT AFFECTED
- registry integrity values: NOT AFFECTED
- C1–C3 / N1–N4 verdicts: NOT AFFECTED
- v1.0.2 publication closure: ESTABLISHED (unaffected)
- maintainer clean-room reproduction: ESTABLISHED (unaffected)

Classification:

    metadata provenance defect: YES
    security behavior regression: NO
    reproduction result invalidated: NO
    historical rewrite required: NO

Corrective action:

build-artifacts.mjs already uses `new Date().toISOString()` at generation time.
The timestamp defect occurred because the v1.0.2 candidate ARTIFACTS.json was
produced with a manual timestamp override rather than by running the script.
Future ARTIFACTS.json files must be generated exclusively by running the script
without manual timestamp overrides.

The v1.0.2 frozen tag is not modified. This record is a post-release documentation
correction on main.
